# Social Science Quiz App 📚

A professional, responsive, and dynamic quiz application built with React.js and Bootstrap. This project is designed to help students practice Social Science questions in Malayalam.

## ✨ Features
* **Randomized Questions (40 Qs):** Uses the Fisher-Yates shuffle algorithm to ensure questions and options appear in a random order every time.
* **Live Timer:** Tracks the total time taken to complete the exam.
* **Interactive UI:** Clean, responsive, and mobile-friendly user interface powered by Bootstrap.
* **Instant Results:** Displays a comprehensive result screen with the final score and time taken.
* **Free Hosting:** Fully configured for deployment on GitHub Pages.

## 🚀 Tech Stack
* **Frontend Library:** React.js
* **Styling / UI:** Bootstrap 5, Custom CSS
* **Data Handling:** Modular JavaScript (ES6+)
* **Deployment:** GitHub Pages (`gh-pages`)
